Why does LAST_VALUE() require 'ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING'?
💡 Click card to flip and reveal answer
Answer & IT Explanation Click to flip back
Because the default window frame with an ORDER BY is RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW. Without the explicit frame clause, LAST_VALUE() evaluates up to the current row, essentially returning the current row value rather than the true last row of the partition!
