1. Python Architecture, Variables, Operators & Control Flow

CPython execution flow, heap memory references, dynamic vs strong typing, modern operators, and loops.

1.1 CPython Internal Engine

Source Code ➔ Bytecode (.pyc) ➔ PVM

Python code (.py) is compiled to bytecode (.pyc) and evaluated inside the Python Virtual Machine (PVM). CPython is written in C, PyPy uses JIT compilation, Jython compiles to JVM bytecode, and Cython transpiles to C extensions. 

import dis

def calculate_fare(dist, surge=1.5):
    return dist * surge * 12.0

# Inspect CPython Bytecode Instructions
dis.dis(calculate_fare)
# 0 LOAD_FAST          0 (dist)
# 2 LOAD_FAST          1 (surge)
# 4 BINARY_OP          5 (*)
# 6 LOAD_CONST         2 (12.0)
# 8 BINARY_OP          5 (*)
# 10 RETURN_VALUE
1.2 Heap Memory Architecture

Variables Are Reference Pointers on the Heap

Variables do not hold data; they hold memory addresses pointing to heap objects. Python is dynamically typed (types checked at runtime) and strongly typed (no implicit type coercion like "5" + 5). 

x = [10, 20]
y = x          # y references the EXACT same memory address
y.append(30)

print(x)       # [10, 20, 30] (x is modified too!)
print(id(x) == id(y))  # True (x is y)
1.3 Primitive Types & Casting

Arbitrary Precision Integers, Floats, Complex, Booleans & None

Python 3 integers have arbitrary precision (they never overflow into negative numbers!). Floats are 64-bit IEEE 754 floating-point numbers. Booleans are a subclass of integers (True == 1, False == 0). 

# 1. Arbitrary Precision Integer (No 32/64-bit overflow!)
big_int = 2 ** 256
print(f"2^256 = {big_int}")

# 2. Type Casting
str_num = "100"
converted_int = int(str_num)      # 100
converted_float = float(str_num)  # 100.0
converted_bool = bool(str_num)    # True (Any non-empty string is True)
empty_bool = bool("")             # False
1.4 Operators & Expressions

Arithmetic, Comparison, Bitwise & Walrus (:=)

The Walrus Operator (:= in Python 3.8+) assigns values inside expressions. Identity (is) checks memory addresses, while Equality (==) checks values. 

# Walrus Operator (:=)
data = [1, 2, 3, 4, 5]
if (n := len(data)) > 3:
    print(f"List has {n} elements (computed once!)")

# 'is' vs '=='
a = [1, 2]
b = [1, 2]
print(a == b)  # True (Values match)
print(a is b)  # False (Different memory addresses!)

Immutability, Slicing & Formatting

5.3 Inheritance & MRO

C3 Linearization & super()

class A:
    def action(self): print("Action A")

class B(A):
    def action(self): print("Action B"); super().action()

class C(A):
    def action(self): print("Action C"); super().action()

class D(B, C): pass

d = D()
d.action()  # Order: D -> B -> C -> A (C3 MRO)
5.4 Polymorphism & Dunder Methods

Operator Overloading (__add__, __repr__)

class Tensor2D:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __add__(self, other):
        return Tensor2D(self.x + other.x, self.y + other.y)
    def __repr__(self):
        return f"Tensor2D({self.x}, {self.y})"

t1 = Tensor2D(2, 3)
t2 = Tensor2D(4, 7)
print(t1 + t2)  # Tensor2D(6, 10)

⚡ 5.5 Memory Optimization with __slots__: 68% RAM Savings

By default, Python instances store attributes in a dynamic dictionary (__dict__), consuming ~153 bytes per object. Declaring __slots__ = ('x', 'y') eliminates __dict__, reducing memory down to 48 bytes per object. 

class OptimizedCoordinate:
    __slots__ = ('lat', 'lon')  # Eliminates instance __dict__
    def __init__(self, lat, lon):
        self.lat = lat
        self.lon = lon

6.1 Metaclasses

Metaclass Singleton Architecture

class SingletonMeta(type):
    _instances = {}
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class DatabaseEngine(metaclass=SingletonMeta):
    def __init__(self):
        print("Connecting to PostgreSQL...")

db1 = DatabaseEngine()
db2 = DatabaseEngine()
print(db1 is db2)  # True (Guaranteed Singleton!)
6.2 Descriptors

The Descriptor Protocol (__get__, __set__)

class PositiveNumber:
    def __set_name__(self, owner, name):
        self.name = name
    def __get__(self, instance, owner):
        return instance.__dict__.get(self.name, 0)
    def __set__(self, instance, value):
        if value <= 0:
            raise ValueError(f"{self.name} must be > 0!")
        instance.__dict__[self.name] = value

class Item:
    price = PositiveNumber()
